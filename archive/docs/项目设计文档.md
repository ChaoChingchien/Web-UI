## 1. 项目概述

### 1.1 目标

构建一个 **AI 团队协作与自动化对话平台**桌面应用。核心能力：

1. **AI 网页版自动化** — 通过 Playwright 操控 AI 网页完成真实对话
2. **AI Team（团队协作）** — 多个 AI 角色分工协作，共同完成复杂任务
3. **子任务管理** — 将复杂任务拆解为子任务，分配给不同 AI 执行，看板跟踪
4. **多接入方式** — 支持网页版自动化、自有 API 接入、本地部署模型

### 1.2 核心特性

| 特性 | 说明 |
|------|------|
| **原生聊天界面** | 用户在自己的 UI 中输入和查看对话 |
| **后台自动化** | Playwright 自动操控 AI 网页（填表、点击、抓取） |
| **AI Team** | 多角色协作，支持流水线/并行/讨论/混合模式 |
| **子任务管理** | 手动/自动拆解任务，看板视图，状态跟踪 |
| **多接入方式** | 网页版 / 自有 API / 本地模型（Ollama 等） |
| **对话持久化** | SQLite 本地存储，全文搜索 |
| **导出功能** | Markdown / 纯文本 / JSON |
| **角色系统** | 预设角色模板 + 用户自定义角色 |

### 1.3 技术栈

| 层级 | 技术 |
|------|------|
| 桌面框架 | Electron |
| 前端 | React + TypeScript + Vite |
| 状态管理 | Zustand |
| 持久化存储 | SQLite (sql.js) + JSON 文件 |
| 网页自动化 | Playwright (Chromium) |
| API 调用 | OpenAI SDK 兼容（支持 Ollama 等本地模型） |
| 打包 | Electron Forge |
| 日志 | electron-log |

### 3.2 Team 工作模式

#### 模式 1: 流水线 (Pipeline)

```
输入 → [研究员] → [写手] → [审核员] → 最终输出
```

每个角色按顺序处理，上一轮输出作为下一轮输入。

```
用户: "帮我写一篇关于 AI 的文章"
  │
  ▼
[研究员] → 搜集 AI 领域最新进展、关键数据
  │
  ▼
[写手] → 基于研究资料撰写文章初稿
  │
  ▼
[审核员] → 检查文章质量，提出修改建议
  │
  ▼
[写手] → 根据建议修改完善
  │
  ▼
最终输出: 高质量文章
```

#### 模式 2: 并行协作 (Parallel)

```
          ┌→ [研究员] → 调研报告 ─┐
输入 ─────├→ [分析师] → 数据分析 ─┼→ [汇总器] → 综合报告
          └→ [创意师] → 创意方案 ─┘
```

多个 AI 同时处理同一任务的不同方面，最后汇总。

#### 模式 3: 讨论 (Debate)

```
用户: "AI 会取代人类工作吗？"
  │
  ▼
[正方 AI] 观点: AI 会取代部分工作
  │
  ▼
[反方 AI] 观点: AI 会创造新工作
  │
  ▼
[正方 AI] 反驳...
  │
  ▼
[反方 AI] 反驳...
  │
  ▼
[裁判 AI] 总结: 综合双方观点，给出平衡结论
```

#### 模式 4: 混合 (Mixed)

用户自由编排，支持流水线和并行的任意组合：

```
              ┌→ [研究员 A] ─┐
输入 → [拆解] ├→ [研究员 B] ─┼→ [写手] → [审核员] → 输出
              └→ [研究员 C] ─┘
```

## 5. 多接入方式设计

### 5.1 接入方式对比

| 方式 | 配置 | 优点 | 缺点 |
|------|------|------|------|
| **Web 自动化** | URL + CSS 选择器 | 免费、无需 API Key | 慢、可能被检测 |
| **API 接入** | API Key + Endpoint | 快速、稳定 | 需要付费 |
| **本地模型** | Ollama/LM Studio URL | 免费、隐私、离线 | 需要硬件 |

### 5.2 提供商配置扩展

### 5.3 统一 AI 调用接口

```typescript
// 统一的 AI 调用方法，根据 provider.type 路由
class AIRouter {
  async chat(provider: AIProvider, messages: ChatMessage[]): Promise<string> {
    switch (provider.type) {
      case 'web':
        return this.webChat(provider, messages);
      case 'api':
        return this.apiChat(provider, messages);
      case 'local':
        return this.localChat(provider, messages);
    }
  }

  // Web: 使用 Playwright 自动化
  private async webChat(provider, messages) { ... }

  // API: 使用 OpenAI SDK（兼容 Ollama/LM Studio）
  private async apiChat(provider, messages) {
    const response = await fetch(`${provider.apiConfig.baseUrl}/chat/completions`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${provider.apiConfig.apiKey}`,
      },
      body: JSON.stringify({
        model: provider.apiConfig.model,
        messages,
        stream: false,
      }),
    });
    const data = await response.json();
    return data.choices[0].message.content;
  }

  // 本地: 与 API 调用方式相同（Ollama 兼容 OpenAI API）
  private async localChat(provider, messages) {
    // Ollama: http://localhost:11434/v1/chat/completions
    // LM Studio: http://localhost:1234/v1/chat/completions
    return this.apiChat({
      ...provider,
      apiConfig: provider.localConfig,
    }, messages);
  }
}
```

## 6. 数据模型

### 6.1 SQLite Schema

```sql
-- ============================================
-- 迁移 001: 基础表（提供商、对话、消息）
-- ============================================

CREATE TABLE IF NOT EXISTS providers (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    icon TEXT DEFAULT '🤖',
    type TEXT DEFAULT 'web' CHECK(type IN ('web', 'api', 'local')),
    is_custom INTEGER DEFAULT 0,
    is_enabled INTEGER DEFAULT 1,
    -- Web 配置
    url TEXT,
    web_config TEXT DEFAULT '{}',
    -- API 配置
    api_config TEXT DEFAULT '{}',
    -- 本地模型配置
    local_config TEXT DEFAULT '{}',
    created_at TEXT DEFAULT (datetime('now')),
    updated_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS conversations (
    id TEXT PRIMARY KEY,
    provider_id TEXT NOT NULL REFERENCES providers(id),
    title TEXT NOT NULL,
    created_at TEXT DEFAULT (datetime('now')),
    updated_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS messages (
    id TEXT PRIMARY KEY,
    conversation_id TEXT NOT NULL,
    role TEXT NOT NULL CHECK(role IN ('user', 'assistant', 'system')),
    content TEXT NOT NULL,
    created_at TEXT DEFAULT (datetime('now')),
    FOREIGN KEY (conversation_id) REFERENCES conversations(id) ON DELETE CASCADE
);

-- ============================================
-- 迁移 002: AI Team 表
-- ============================================

CREATE TABLE IF NOT EXISTS roles (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    icon TEXT DEFAULT '🤖',
    system_prompt TEXT DEFAULT '',
    provider_id TEXT REFERENCES providers(id),
    config TEXT DEFAULT '{}',       -- temperature, maxTokens 等
    is_custom INTEGER DEFAULT 1,
    created_at TEXT DEFAULT (datetime('now')),
    updated_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS teams (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT DEFAULT '',
    mode TEXT DEFAULT 'pipeline' CHECK(mode IN ('pipeline', 'parallel', 'debate', 'mixed')),
    config TEXT DEFAULT '{}',
    created_at TEXT DEFAULT (datetime('now')),
    updated_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS team_roles (
    id TEXT PRIMARY KEY,
    team_id TEXT NOT NULL REFERENCES teams(id) ON DELETE CASCADE,
    role_id TEXT NOT NULL REFERENCES roles(id),
    role_order INTEGER DEFAULT 0,
    parallel_group INTEGER DEFAULT 0,
    input_mapping TEXT DEFAULT 'original' CHECK(input_mapping IN ('original', 'previous', 'all_previous')),
    UNIQUE(team_id, role_id)
);

CREATE TABLE IF NOT EXISTS team_runs (
    id TEXT PRIMARY KEY,
    team_id TEXT NOT NULL REFERENCES teams(id),
    input TEXT NOT NULL,
    status TEXT DEFAULT 'running' CHECK(status IN ('running', 'completed', 'failed', 'stopped')),
    final_output TEXT DEFAULT '',
    started_at TEXT DEFAULT (datetime('now')),
    completed_at TEXT
);

CREATE TABLE IF NOT EXISTS team_run_outputs (
    id TEXT PRIMARY KEY,
    run_id TEXT NOT NULL REFERENCES team_runs(id) ON DELETE CASCADE,
    role_id TEXT NOT NULL,
    role_name TEXT NOT NULL,
    input_text TEXT DEFAULT '',
    output_text TEXT DEFAULT '',
    status TEXT DEFAULT 'pending' CHECK(status IN ('pending', 'running', 'done', 'error')),
    error_text TEXT DEFAULT '',
    started_at TEXT,
    completed_at TEXT
);

-- ============================================
-- 迁移 003: 子任务管理表
-- ============================================

CREATE TABLE IF NOT EXISTS projects (
    id TEXT PRIMARY KEY,
    name TEXT NOT NULL,
    description TEXT DEFAULT '',
    status TEXT DEFAULT 'active' CHECK(status IN ('active', 'completed', 'archived')),
    created_at TEXT DEFAULT (datetime('now')),
    updated_at TEXT DEFAULT (datetime('now'))
);

CREATE TABLE IF NOT EXISTS sub_tasks (
    id TEXT PRIMARY KEY,
    project_id TEXT NOT NULL REFERENCES projects(id) ON DELETE CASCADE,
    parent_id TEXT REFERENCES sub_tasks(id),
    title TEXT NOT NULL,
    description TEXT DEFAULT '',
    status TEXT DEFAULT 'todo' CHECK(status IN ('todo', 'in_progress', 'review', 'done', 'cancelled')),
    priority TEXT DEFAULT 'medium' CHECK(priority IN ('low', 'medium', 'high', 'urgent')),
    assignee_role_id TEXT REFERENCES roles(id),
    assignee_provider_id TEXT REFERENCES providers(id),
    conversation_id TEXT REFERENCES conversations(id),
    task_order INTEGER DEFAULT 0,
    due_date TEXT,
    completed_at TEXT,
    created_at TEXT DEFAULT (datetime('now')),
    updated_at TEXT DEFAULT (datetime('now'))
);

-- ============================================
-- 迁移 004: 索引
-- ============================================

CREATE INDEX IF NOT EXISTS idx_messages_conversation ON messages(conversation_id);
CREATE INDEX IF NOT EXISTS idx_conversations_provider ON conversations(provider_id);
CREATE INDEX IF NOT EXISTS idx_team_roles_team ON team_roles(team_id);
CREATE INDEX IF NOT EXISTS idx_team_runs_team ON team_runs(team_id);
CREATE INDEX IF NOT EXISTS idx_team_run_outputs_run ON team_run_outputs(run_id);
CREATE INDEX IF NOT EXISTS idx_sub_tasks_project ON sub_tasks(project_id);
CREATE INDEX IF NOT EXISTS idx_sub_tasks_parent ON sub_tasks(parent_id);
CREATE INDEX IF NOT EXISTS idx_sub_tasks_status ON sub_tasks(status);
